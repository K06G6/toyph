# Implementation Plan: Marquee Text Animation

**Branch**: `marquee` | **Date**: 2026-04-08 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/marquee/spec.md`

## Summary

Add a `SCROLLING_TEXT` animation type that renders Unicode text as a wide bitmap matrix using bundled bitmap fonts, then scrolls it right-to-left (classic marquee) across the 13x13 LED grid. Text-to-matrix conversion happens once at startup; each frame shifts a 13x13 viewport by one column. The animation is bookended by fade-to-black and fade-from-black transitions reusing the existing `CrossFadeTransition`. A Python converter tool generates bitmap font JSON files from TTF/OTF sources.

## Technical Context

**Language/Version**: Kotlin (Android, compileSdk 36, minSdk 34, AGP 9.1.0 built-in Kotlin)
**Primary Dependencies**: GlyphMatrix SDK 2.0 (`.aar`), kotlinx-coroutines-android 1.9.0, `org.json`
**Storage**: JSON asset files (`app/src/main/assets/`)
**Testing**: Visual verification on physical Nothing Phone 4a Pro
**Target Platform**: Nothing Phone 4a Pro (Android, AOD)
**Project Type**: mobile-app (AOD glyph toy)
**Performance Goals**: Single `IntArray.copyOf()` per frame, minimize CPU wake-ups on AOD
**Constraints**: 13x13 grid (169 cells), 0-4095 brightness, >=30ms frame interval, battery-efficient AOD
**Scale/Scope**: Single-device AOD toy, handful of bundled bitmap fonts

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

| Principle | Status | Evidence |
|-----------|--------|----------|
| I. Grid Fidelity | PASS | Each frame is a 13x13 viewport (169 integers) extracted from the wide text matrix. Brightness values are 0 or MAX_BRIGHTNESS (4095). No out-of-bounds access — matrix is pre-padded with GRID_SIZE blank columns on each side. |
| II. Battery Discipline | PASS | Text-to-matrix conversion runs once at startup (not per-frame). Per-frame work: one `IntArray(169)` allocation + array copy of 13-column window. Frame interval configurable, enforced >=30ms by existing ToyConfig parsing. Trailing interval between animations prevents continuous LED driving. |
| III. SDK Compliance | PASS | No SDK API changes. Uses existing `GlyphMatrixManager.setMatrixFrame()` path. No new device constants. API key handling unchanged. |
| IV. Animation as Interface | PASS | New `ScrollingTextAnimation` implements `GlyphAnimation`. Added to `createAnimation()` type mapping with `"SCROLLING_TEXT"` key. Referenced by name in `toy-config.json`. Service orchestrates fade transitions; animation only generates frames. |
| V. Data-Driven Design | PASS | Font data in JSON asset files under `assets/fonts/`. Text and font path configured in `toy-config.json`. No hardcoded patterns or text in Kotlin source. Pattern authoring via converter tool without touching animation code. |

**Gate result: ALL PASS — no violations.**
