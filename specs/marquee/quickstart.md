# Quickstart: Marquee Text Animation

## Overview

Adds marquee-style scrolling text to the glyph toy. Text is pre-rendered to a wide pixel matrix at startup using bitmap fonts stored as JSON. The animation scrolls the text right-to-left across the 13x13 LED grid, bookended by fade-to-black and fade-from-black transitions.

## Files to Create

| File | Purpose |
|------|---------|
| `app/src/main/java/com/toyph/app/animations/ScrollingTextAnimation.kt` | GlyphAnimation impl: extracts 13x13 viewport from wide text matrix at each tick |
| `app/src/main/java/com/toyph/app/animations/TextBitmapRenderer.kt` | Loads bitmap font JSON, converts text string to wide pixel matrix |
| `app/src/main/assets/fonts/default.json` | First bundled bitmap font (generated by converter tool) |
| `tools/font-to-glyph.py` | Python script: TTF/OTF → bitmap font JSON converter |
| `tools/README.md` | Converter usage documentation |

## Files to Modify

| File | Change |
|------|--------|
| `app/src/main/java/com/toyph/app/ToyConfig.kt` | Add `text: String?` and `font: String?` fields to `AnimationConfig` |
| `app/src/main/java/com/toyph/app/GlyphToyService.kt` | Load fonts, create `ScrollingTextAnimation`, add fade-to/from-black around it |
| `app/src/main/assets/toy-config.json` | Add `SCROLLING_TEXT` animation entry |

## Implementation Order

1. **ToyConfig.kt** — extend `AnimationConfig` with optional `text`/`font` fields
2. **TextBitmapRenderer.kt** — font loading + text-to-matrix conversion
3. **ScrollingTextAnimation.kt** — viewport extraction per frame
4. **GlyphToyService.kt** — wire up font loading, animation creation, fade orchestration
5. **tools/font-to-glyph.py** + **tools/README.md** — converter tool
6. **Generate default.json** — run converter on a suitable pixel font
7. **toy-config.json** — add SCROLLING_TEXT entry, test on device

## Key Architecture Decisions

- **One-time conversion**: `TextBitmapRenderer.renderText()` runs once at startup. Returns a flat `IntArray` (13 rows x paddedWidth columns) and the width.
- **Per-frame cost**: `generateFrame(tick)` copies a 13x13 window (169 integers) from the wide matrix. No computation beyond array copy.
- **Fade orchestration**: Service loop detects `SCROLLING_TEXT` type and plays `CrossFadeTransition(image→black)` before and `CrossFadeTransition(black→image)` after the scroll animation.
- **Font format**: JSON with per-character width + binary pixel array. Schema in `contracts/font-schema.json`.

## Example Config

```json
{
  "animations": [
    { "type": "SCANLINE", "frameIntervalMs": 50, "trailingIntervalMs": 1000 },
    {
      "type": "SCROLLING_TEXT",
      "text": "THIS IS THE WAY",
      "font": "fonts/default.json",
      "frameIntervalMs": 80,
      "trailingIntervalMs": 1000
    }
  ]
}
```

## Testing

1. Run `tools/font-to-glyph.py` on a TTF to generate `fonts/default.json`
2. Add SCROLLING_TEXT to `toy-config.json`
3. `./gradlew installDebug` and verify on physical device:
   - Current image fades to black
   - Text scrolls smoothly right-to-left
   - Screen fades back to original image
   - Other animations continue normally
